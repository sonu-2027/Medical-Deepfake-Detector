# 🩺 Medical Deepfake Detector
 
A Deep Learning based system that detects manipulated or fake medical images using Convolutional Neural Networks (CNNs).

# 🚧 Project Status: Under Development
 
## 📌 Overview
 
Medical image tampering and deepfakes can lead to incorrect diagnoses and serious healthcare risks. This project aims to identify whether a medical image is genuine or manipulated using a CNN-based classification model.
 
## 🚀 Features
 
- Detects real and fake medical images
- CNN-based image classification
- Image preprocessing and augmentation
- Training and evaluation pipeline
- Visualization of model performance
 
## 🛠️ Tech Stack
 
- Python
- PIL + Torchvision
- CNN (DenseNet121)
- Yolo (Ultralytics + OpenCV)
- NLP
- React UI
- FastAPI
- SQL Database
- Google Colab
